A GAME THAT IS BUILDING ITSELF · build diary

What is this? An AI is building a complete fighter-jet game from scratch — you fly an F-22 Raptor over real places on Earth (Nevada, Alaska, the Pacific), right in your web browser. Nothing to download or install.

How does it work? The game gets built in 21 parts, like chapters. Each bar below fills up as that part gets done. Gold bar = finished. Striped bar = being built right now. The big number is how much of the whole game exists so far.
